# Offline support and diagnostics

EmberSoft has not published a support email or website for this release. The included manual and in-plugin Help/About work offline. Do not send passwords, licence keys, private audio or other sensitive information in a bug report.

If the plugin is not found, close the DAW, verify the complete bundle exists, check the DAW's VST3 scan folder and rescan. A current-user installation may need its folder added manually. For an audio-device problem in the standalone, open its device settings and select the correct input/output device.

If an issue persists, record:

1. EMBERFOX version and whether VST3 or standalone.
2. Windows version, host/version, sample rate and buffer size.
3. Steps to reproduce and expected/actual behavior.
4. Selected mode and control values, whether automation/bypass is involved, and whether it happens with the editor closed.
5. Relevant host crash/error log and an optional minimal project that contains no private recordings.

Keep this information with your project or report a non-sensitive reproduction through [GitHub issues](https://github.com/SeksiabiSimmu/EMBERFOX/issues). Old release ZIPs can be used for rollback; back up DAW projects before testing an update.
